# 시니어 영어회화 선생님

스마트폰에서 로그인 없이 이용하는 여행 영어 연습 홈페이지입니다.

## 기능
- 카페·레스토랑·길 묻기·호텔·입국 심사·인사
- 상황별 7쌍의 영어 문장과 한국어 뜻
- 문장별/전체 듣기, 정지, 속도 선택
- 한 질문씩 역할 연습, 예시 답변 확인
- ChatGPT용 자유 대화 요청문 생성·복사

## 이용
index.html을 열거나 GitHub Pages 주소로 접속합니다. 음성은 Web Speech API를 사용하며 기기별 지원과 영어 음성 설정에 따라 달라집니다.

이 홈페이지는 AI 서버나 API 키를 사용하지 않습니다. 자유 대화와 피드백은 각자의 ChatGPT에서 진행하며 해당 계정의 사용 한도가 적용됩니다. 홈페이지는 음성을 녹음하거나 답변을 채점하지 않습니다.

## 배포
GitHub Settings → Pages → Deploy from a branch → main / (root).
